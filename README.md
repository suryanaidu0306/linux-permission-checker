# Linux File Permission Checker

## 📌 Description

This project is a Bash-based Linux security tool that checks
file permissions and displays information about read, write,
and execute permissions.

## 🛠️ Technologies Used

- Linux
- Bash Shell
- Linux File Permissions
- `stat`
- `chmod`

## 📂 Project Files

- `permission_checker.sh` - Permission checking script
- `README.md` - Project documentation

## 🚀 How to Run

Give execution permission:

```bash
chmod +x permission_checker.sh
